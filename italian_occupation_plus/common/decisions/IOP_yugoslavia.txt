# ============================================================
# Italian Occupation Plus v0.1 - Yugoslavia
# Works like Reichskommissariats Plus, but for Italy:
# 1) As Italy, occupy Yugoslav land.
# 2) Found ICR / ISE / IMT with the "Establish" decisions.
#    Founding requires controlling the capital state only.
#    Any other initial states you control transfer automatically.
# 3) Use "Determine fate of ..." decisions to assign further
#    states via event (choose Croatia / Serbia / Montenegro).
# 4) Zara (163) and Istria (852) are special: give to Croatia
#    OR annex to Italy (adds Italian core).
# ============================================================
