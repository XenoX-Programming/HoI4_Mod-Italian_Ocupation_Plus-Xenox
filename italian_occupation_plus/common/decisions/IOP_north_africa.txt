# Italian Occupation Plus v0.0.16 - North Africa
# 1) As Italy, control Tripoli (starts Italian - INA can be
#    founded on day one).
# 2) Found INA with the "Establish" decision.
#    Founding requires controlling the capital state only (448 Tripoli).
#    Any other initial states you control transfer automatically.
# 3) Use the grouped "Transfer ..." decisions to hand further
#    regions straight to INA (cores + transfer, no event - INA
#    is the only recipient). Each needs INA to exist and Italy
#    to control at least one state of the group; every controlled
#    state of the group transfers.
# 4) Sidi Ifni (783) is special: its decision fires an event to
#    give it to INA OR integrate it into Italy proper.
# NOTE: none of these redistributed states has any other fate
# decision - each region is handled exactly once, here.
# ============================================================
